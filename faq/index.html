応募・選考について

Q 応募資格はありますか?

ご希望の職種に関わるご経験や、住まいづくりへの関心を、エントリーフォームでお知らせください。

Q 応募方法は?

弊社採用サイトからエントリーしてください。

Q 選考フローは?

書類選考の後、面接(2回程度)を実施し、内定となります。

Q 選考にかかる時間は?

応募から内定まで、おおむね2週間〜1ヶ月程度です。

Q 面接では何を聞かれますか?

これまでのご経験や志望動機、今後挑戦したいことなどを中心にお伺いします。

Q 面接官はどんな人ですか?

人事担当者と配属予定部署の社員が担当します。リラックスしてお話しください。

キャリアについて

Q 自分の希望するキャリアパスに進むことはできますか?

定期的なキャリア面談で希望を伺い、研修制度や配属に反映しています。

Q 転勤はありますか?

業務の必要に応じて、転勤が発生する場合があります。

Q 転勤の希望は出せますか?

年1回の自己申告制度で勤務地の希望を申請できます。

Q ワークライフバランスは?

フレックスタイム制やリモートワークを活用し、メリハリのある働き方ができます。

Q 具体的にはどのような制度がありますか?

フレックスタイム制、短時間勤務制度、資格取得支援制度などがあります。

Q 育児休暇制度はありますか?

あります。男女問わず取得実績があり、復帰後は短時間勤務も選択できます。

福利厚生について

Q どのような福利厚生制度がありますか?

各種手当、財形貯蓄、社会保険完備のほか、社員向けジムや社内託児所を設けています。詳しくは福利厚生ページをご覧ください。

Q 財形貯蓄制度の内容は?

財形貯蓄を支援する制度です。

Q 社内イベントの内容は?

社員旅行や懇親会など、社員同士の交流を深めるイベントを定期的に開催しています。

Q 部活動について教えてください。

フットサル部や登山部など、有志による部活動が活動中です。新設の申請も可能です。

Q 資格取得支援制度はいくら補助が出ますか?

対象資格の受験料と教材費を、会社の定める上限額まで補助します。

Q 年次有給休暇について教えてください

初年度は10日付与されます。年度途中入社の場合は比例付与となります。
